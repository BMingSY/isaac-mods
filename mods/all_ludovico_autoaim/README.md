# 全鲁多维科 + 自动索敌

[Steam 订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3811712323) · [安装包](https://github.com/BMingSY/isaac-mods/releases/download/all_ludovico_autoaim-v0.3/all_ludovico_autoaim-0.3.zip)

适用于《以撒的结合：忏悔+》。普通道具底座全部变为鲁多维科科技（329）。

## 操作

- 拿到鲁多维科后，按一下任意攻击方向键开启自动索敌，再按一下关闭。长按只切换一次，松开所有攻击方向后才能再次切换。
- 默认键盘使用 ↑ ↓ ← →；修改键位后使用绑定的攻击方向键，手柄使用攻击摇杆。
- 角色上方显示 `AUTO ON / AUTO OFF`。开始或继续一局默认手动模式，切换房间保留开关状态。
- 自动模式追击可受伤的敌人，目标死亡或不可受伤后寻找下一个；没有目标时待命。
- 镜面世界正常索敌，状态文字保持正向显示。

重复拾取产生的小眼泪继续围绕主眼泪旋转；鲁多维科激光环使用环的边缘接触敌人。

## 保留的道具

全家福、照片、两块钥匙碎片、刀柄/刀刃、两块损坏的铲子、妈妈的铲子、爸爸的便条、教条，以及其他带任务标记的道具。

金币、钥匙、炸弹、心、卡牌和饰品不替换。初始背包里的道具不替换。

## 安装

在创意工坊订阅，重启游戏后在 **MODS** 菜单启用“全鲁多维科 + 自动索敌”。

手动安装时，将安装包中的 `all_ludovico_autoaim` 文件夹放入游戏使用的 `mods` 目录。

游玩时关闭其他替换全部道具的 Mod。
