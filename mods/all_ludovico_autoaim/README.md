# Ludovico Auto Aim

适用于《以撒的结合：忏悔+》。

持有鲁多维科科技时，按一下任意攻击方向键开启自动索敌，再按一下关闭；长按只切换一次。角色上方显示 AUTO ON / AUTO OFF，换房保留开关状态。

与 Ludovico Auto Aim V2 二选一启用。

全道具替换功能已移至 [All Items Into One](https://steamcommunity.com/sharedfiles/filedetails/?id=3825974753)。需要全鲁多维科时，同时启用该 Mod，将目标道具 ID 设为 329。
