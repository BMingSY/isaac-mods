# 全启明星 + 贪吃蛇队列

[Steam 订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3813399534) · [安装包](https://github.com/BMingSY/isaac-mods/releases/download/all_bethlehem_snake-v0.5/all_bethlehem_snake-0.5.zip)

普通道具变为启明星／伯列恒之星（651），保留全家福、照片、钥匙碎片、刀柄／刀刃等任务道具。

保留游戏和汉化 Mod 提供的道具名称、拾取描述及 EID 说明。

每份启明星对应一颗星星。队首保留原版引路行为，后排按固定编号沿队首路线跟进，以一个光环半径为目标间距；落后时提速，接近目标时减速。新星星从队首所在的位置逐渐加入队尾。

整队的行进速度以最后一颗启明星的位置为准：队尾落后玩家时提速，追到玩家所在房间后恢复正常速度，队尾也超过玩家后才减速。队尾在其他房间时仍参与判断，后排的追赶速度会随整队速度提高。一份启明星保留原版速度行为。

队列位置按整层地图保存，换房不会把星星搬到玩家身边。星星实际位于其他房间时，当前房间不生成它的星星和光环，也不提供加成；队列仍在原路径上继续移动。保存退出后续玩会恢复编号和队列位置。

站在任意一颗星星的光环内，都能获得全部启明星叠加后的效果：伤害 ×1.2^数量、射速 ×2.5^数量、追踪眼泪，普通受伤的免伤概率为 1−0.5^数量。重叠区域不会额外重复叠加。射速最高 120 发／秒。

一份启明星只计算一次原版加成：基础射速为 2.73 时，光环内约为 6.82；两份约为 17.05（以未四舍五入的基础数值计算）。队尾光环使用原版圣光地面效果实体，范围与队首一致。

在 MODS 菜单启用「全启明星 + 贪吃蛇队列」，关闭旧版「全伯列恒之星 + 光环叠加」及其他替换全部道具的 Mod。控制台重复输入 `giveitem c651` 可以增加星星。

## 更新

- **0.5**：改为根据队尾的位置决定整队速度，避免队首提前减速拖慢整队；提高后排在快速行进时的追赶速度，仍连续移动。兼容 0.3、0.4 存档续玩。

- **0.4**：修正换房后后排出现在新房间、再追向队首的问题。队列位置与显示实体分开保存，仅在实际所在房间显示；丢弃旧房间采样，避免路径被入口坐标重置。兼容 0.3 存档续玩。

- **0.3**：改用原版光环效果实体；固定队列编号并保存楼层路径；改进排队移动并修正隐藏星星误加属性。后排使用有速度上限的连续移动。

- **0.2**：恢复原版道具文本，修正队首原版加成被重复计算、队尾光环缺失和光环之间的加成差异。

从 0.2 的旧局升级时，如果原版队首正在别的房间，后排会等到首次看到队首后重新加入队列。
