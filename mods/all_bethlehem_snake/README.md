# Bethlehem Snake

适用于《以撒的结合：忏悔+》。

每份启明星对应一颗星星，沿原版路线排成队列。整队速度由队尾位置决定，换房和续玩保留队列位置。

站在任意一颗星星的光环内，获得全部启明星叠加后的效果：伤害 ×1.2^数量、射速 ×2.5^数量、追踪眼泪，普通受伤免伤概率为 1−0.5^数量。重叠区域不重复叠加，射速最高 120 发／秒。

全道具替换功能已移至 [All Items Into One](https://steamcommunity.com/sharedfiles/filedetails/?id=3825974753)。需要全启明星时，同时启用该 Mod，将目标道具 ID 设为 651。
