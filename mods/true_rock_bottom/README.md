# 真·谷底石

[Steam 订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3812009224) · [安装包](https://github.com/BMingSY/isaac-mods/releases/download/true_rock_bottom-v0.4/true_rock_bottom-0.4.zip)

修改谷底石（562），让保留的历史最高属性参与后续加成计算，属性降低后也能继续获得提升。

例如伤害保留在 10、原本实际值降到 5 后，再获得 +1 的最终伤害加成会变成 11；获得新的 ×2 伤害倍率会变成 20。

影响伤害、射速、移速、射程、弹速和幸运。
