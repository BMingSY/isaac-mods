# 队伍 DPS / Party DPS

ACT 风格的独立 DPS 面板，按伤害排序显示自己和队友的 DPS、累计伤害与伤害占比。默认面板大小 65%，位于左下角，文字保持原始像素大小。

安装 **Mod Config Menu** 后，在配置菜单的 **Party DPS／队伍 DPS** 中调整显示、统计范围、面板大小、背景透明度和位置。支持中文版配置菜单，设置与 F6 菜单同步。

- **F6**：设置菜单；鼠标或方向键调整显示、统计模式、缩放、透明度和位置。
- **F7**：切换本场／整局统计。
- **F8**：显示／隐藏面板。
- **F9**：解锁／锁定面板；解锁后用鼠标拖动标题栏。位置和显示设置自动保存。

将 `party_dps` 文件夹放入游戏使用的 `mods` 目录，在 MODS 菜单启用。

使用 **isaac-lan API v1** 联机时，房主和需要面板的队友启用此 Mod。房主统计全队伤害，客机每半秒请求一次只读快照；分房战斗也归入同一队伍排行。房主未启用时，客机面板显示提示。无需 REPENTOGON。

本场从首次造成伤害开始，连续 5 秒没有伤害后结束，保留结果到下一场。整局 DPS 使用所有战斗的累计时间，探索和暂停不计入分母。伤害按敌人实际 HP 减少量统计，排除未生效攻击、护甲吸收及过量伤害；双子和遗忘者的副角色归入所属玩家。无法追溯到玩家的环境伤害或第三方自定义伤害不分配给任何玩家。换层保留整局统计；保存继续恢复已记录的伤害。沙漏回退保留历史输出记录。

游戏会合并同一敌人的伤害缓冲；多人同帧命中时，按伤害回调数值的比例分摊实际扣血。不足一秒的战斗按一秒计算 DPS。

调试控制台命令 `partydps settings` 打开设置，`partydps position` 恢复默认位置，`partydps show`／`partydps hide` 设置显示状态。
