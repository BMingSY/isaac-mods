# Sacred Heart Stacking

适用于《以撒的结合：忏悔+》。

让重复获得的圣心继续叠加伤害：从第二颗起，每多一颗执行一次「伤害 = 当前伤害 × 2.3 + 1」。按各玩家当前持有数量计算，失去圣心时刷新。

全道具替换功能已移至 [All Items Into One](https://steamcommunity.com/sharedfiles/filedetails/?id=3825974753)。需要全圣心时，同时启用该 Mod，将目标道具 ID 设为 182。
