# 坨坨变身 / Poop Boss Forms

使用原版主动道具 **大便（ID 36）**，变成坨坨、红坨坨、黑坨坨或滑坨坨。变身持续到本局结束，换房、换层和保存续玩后保留；再次使用大便，切换到当前选择的形态。

适用于忏悔／忏悔+，无需 REPENTOGON 或其他前置。

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3814236696) · [下载 v1.2](https://github.com/BMingSY/isaac-mods/releases/tag/poop_boss_forms-v1.2)

## 操作

| 操作 | 效果 |
| --- | --- |
| 轻按并松开 **Ctrl** | 选择下一次变身，同时按原版规则切换副手、卡牌和胶囊。形态图标固定在硬币右侧，当前选择高亮 |
| **空格**／主动道具键 | 使用大便并变身，正常消耗 1 格充能 |
| **WASD**／移动摇杆 | 普通角色移动，保留移速、碰撞和飞行能力 |
| **方向键**／攻击摇杆 | 释放对应攻击；每第 4 次齐射或挥砍附带一次吹哨召唤 |
| **Q**／口袋物品键 | 使用当前选中的副手、卡牌或胶囊；选中 **Poop Boss Rush** 时发动冲刺 |
| 长按 **Ctrl** | 按原版规则丢弃饰品／口袋物品，不额外切换 Boss 选择 |

手柄使用游戏绑定的“丢弃／切换”和“使用卡牌／副手”按钮。

冲刺使用与里犹大“暗夜刺刀”相同的永久副手槽，可以与卡牌／胶囊切换。**变身后原有永久副手会被冲刺替换**。冲刺第一次获得时充满，之后按原版的一格清房充能规则恢复；切换形态不会免费充能。

## 形态

| 形态 | 弹幕与召唤 | 一次冲刺主动 |
| --- | --- | --- |
| 坨坨 | 三发扇形，召唤 1～3 个友好粪滴 | 连冲 3 段 |
| 红坨坨 | 三发扇形，在前方空地生成红大便；没有空地时召唤红粪滴 | 较慢的 4 段短冲刺 |
| 黑坨坨 | 八方向环形，召唤 1～3 只蓝蜘蛛 | 1 段高速冲刺 |
| 滑坨坨 | 三发扇形，召唤 1～3 个 Brownie 玉米粪滴 | 连冲 2 段，沿途留下友方棕色减速伤害液体 |

冲刺优先沿攻击方向，没有攻击输入时取移动方向，再没有输入时取上次朝向。撞墙反弹，期间获得短暂保护，段间可用攻击／移动输入调整下一段方向。每个敌人在每段中最多受到一次碰撞伤害，整套全部命中的总伤害为 **25 × 当前伤害 + 10**，平均分配到各段；3.5 伤害时合计 97.5。

吹哨召唤在已有 18 个相关友军时停止增加；接触大便转化不受此上限限制。

## 武器与特效

攻击由原版负责发射、蓄力和多发，Mod 将每发攻击扩展为三发扇形或八方向阵型。三眼、双发、四眼等道具保留原版发射数量与射速变化：三发形态分别为 9、6、12 发；黑坨坨分别为 24、16、32 发。

普通泪弹继承角色的伤害、弹速、射程，以及追踪、穿透、中毒、分裂等泪弹特效。幸运触发效果由原版判定，保留触发后的伤害倍率和外观。玄秘魔眼可按攻击方向操控已发出的泪弹。

| 武器 | 变身后的攻击 |
| --- | --- |
| 硫磺火 | 蓄满后松开，发射三束／八方向血激光；未蓄满松开则取消 |
| 妈刀 | 按住蓄力、松开投出三把／八把刀，回收后再次蓄力；支持短蓄力投掷 |
| 科技 | 按原版射速发射科技激光，每束扩展为 Boss 阵型 |
| 科技 X | 蓄力后松开发射三枚／八枚光环，蓄力影响大小和伤害 |
| 剖腹产 | 保留原版蓄力发射、胎儿追踪及胎儿武器组合，每发扩展成 Boss 阵型 |
| 大宝剑（英灵剑） | 保留原版挥砍、蓄力回旋斩及近战范围，发出的剑气扩展成 Boss 阵型 |

这些武器使用原版攻击实体和伤害判定，随角色当前属性变化。蓄力时长、跨房间保留蓄力和蓄力指示均按原版处理；开启游戏中的蓄力条设置可查看进度。镜子房中的攻击、朝向和冲刺沿用原版坐标转换。剑气及同次攻击中的多发弹幕不会重复计算召唤次数。

炸弹博士、史诗胎儿、鲁多维科、骨棒等其他武器保留原版输入和攻击。能够按泪弹扩展的攻击会使用 Boss 阵型；持续操控武器或特殊判定不保证扩展阵型与召唤计数。未逐一验证全部道具组合。

## 大便、炸弹与外观

- 接触完整或部分损坏的大便障碍物，会摧毁它并生成对应的原版友好粪滴，支持普通、红、玉米、金、彩虹、黑、白大便。
- 地上保留可走过的残渣，往返房间不会还原或重复招募；同一位置新生成的大便仍可转化。红大便招募后留下普通残渣，防止再生。
- 保留原版打碎掉落、彩虹／黑大便效果，以及脏心的额外粪滴。变身期间免疫红大便接触伤害。
- 炸弹获得屁股炸弹效果；特殊炸弹保留自己的形态和其他属性。
- Boss 外观随攻击或移动方向左右转身。受击、使用道具和拾取道具时保持 Boss 外观，保留原版效果和动作时长；死亡复用 Boss 自带动画。

## 安装与使用

在创意工坊订阅，或下载压缩包，将 `poop_boss_forms` 文件夹放入游戏实际使用的 `mods` 目录。完整退出并重启游戏，在 **MODS** 中启用 **坨坨变身 / Poop Boss Forms**。请避免同时启用手动安装版和创意工坊版。

推荐用自带大便的普通小蓝人（???）开局：轻按 Ctrl 选形态，再按空格变身。Mod 不会自动给予大便。

已启用调试控制台时，可使用 `poopboss test` 给玩家 1 一颗充满的大便（替换主手主动），或使用 `poopboss charge` 充满当前的大便和冲刺。

## 兼容说明

Boss 贴图与动画复用游戏自带资源。冲刺使用独立制作的道具图标。
