# D6 通关宝箱

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3813446674) · [GitHub 安装包](https://github.com/BMingSY/isaac-mods/releases/download/d6_ending_chest-v0.1/d6_ending_chest-0.1.zip)

适用于《以撒的结合：忏悔+》。

使用 **D6** 时，当前房间中可重置的普通道具底座必定变成通关大宝箱。宝箱出现约一秒后可以接触，进入后播放虚空层／精神错乱的结局并结束本局；在其他楼层也使用同一结局。

D6 正常消耗充能。空底座、其他拾取物和原有通关宝箱不变；保留全家福、照片、钥匙碎片、刀柄／刀刃、铲子组件、爸爸的便条、教条及其他任务道具。D100、永恒 D6 等其他骰子保持原有行为。汽车电池不会重复生成宝箱。

只修改使用 D6 时的效果，不替换道具池中的道具，也不自动给予角色 D6。已经变出的宝箱会随房间保存，换房或保存退出后继续有效。

## 安装与试玩

将 `d6_ending_chest` 文件夹放入游戏的 `mods` 目录，在 MODS 菜单启用「D6 通关宝箱 / D6 Ending Chest」。

可以用自带 D6 的以撒开局，进入有道具的房间后使用 D6。也可以通过控制台输入 `giveitem c105` 获得 D6，输入 `spawn 5.100.1` 生成一个道具底座，输入 `debug 8` 开启无限主动充能后测试（再次输入可关闭）。
