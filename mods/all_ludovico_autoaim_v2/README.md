# Ludovico Auto Aim V2

适用于《以撒的结合：忏悔+》。

每份鲁多维科科技对应一颗同尺寸大球，共享伤害和特效，每颗大球独立索敌。

按一下任意攻击方向键切换自动索敌，长按只切换一次；手动模式同时移动所有大球。与 Ludovico Auto Aim 二选一启用。

全道具替换功能已移至 [All Items Into One](../all_items/)。需要全鲁多维科时，同时启用该 Mod，将目标道具 ID 设为 329。
