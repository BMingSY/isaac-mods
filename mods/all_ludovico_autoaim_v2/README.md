# 全鲁多维科 + 自动索敌 V2

[Steam 订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3811830257) · [安装包](https://github.com/BMingSY/isaac-mods/releases/download/all_ludovico_autoaim_v2-v0.3/all_ludovico_autoaim_v2-0.3.zip)

适用于《以撒的结合：忏悔+》。

- 普通道具全部变为鲁多维科科技（329），保留全家福、照片、钥匙碎片、刀柄/刀刃等任务道具。
- 修改原版鲁多维科科技的叠加效果：原版重复拾取产生围绕主球的小球；V2 改为每份道具对应一颗同尺寸大球，共享伤害和特效。
- 每颗大球独立锁定敌人，优先分头攻击；敌人较少时可以共同攻击。
- 按一下任意攻击方向开启自动索敌，再按一下关闭。长按只切换一次，松开全部攻击方向后才能再次切换。
- 手动模式同时移动所有大球。角色头上显示 `AUTO ON / AUTO OFF`，切换房间保留开关状态。
- 支持手柄、镜面世界和鲁多维科激光环。

在创意工坊订阅，重启游戏后启用“全鲁多维科 + 自动索敌 V2”。手动安装时，将 `all_ludovico_autoaim_v2` 文件夹放入游戏的 `mods` 目录。

同时关闭旧版“全鲁多维科 + 自动索敌”和其他替换全部道具的 Mod。
